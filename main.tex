\section*{Motivation and Problem}
Shor's polynomial-time factoring algorithm illustrates quantum computing's advantage over the best known classical methods~\cite{shor}. Realizing such speedups requires reliable computation despite noisy physical operations. \textbf{Quantum error correction (QEC)} protects logical information across physical qubits; a \emph{QEC code} specifies the encoding and parity checks used to diagnose faults without reading the protected information.

Expert-designed constructions and automated search balance reliability, qubit overhead, and hardware constraints~\cite{olle}. Inexpensive code-level screening can mis-rank circuit-level performance, while noisy simulation and decoding are costly~\cite{omniqec}. \textbf{How can costly evaluation feedback improve generation and screening to reduce the compute needed to find a suitable code?}

\section*{Proposed Innovation: Adaptive Dual-Loop Discovery}
We propose \textbf{AgentQEC}, a multi-agent framework coupling a fast loop for candidate generation and screening with a slow loop for circuit-level evaluation. Our focus is to use costly evaluation feedback both to guide subsequent code construction and to improve inexpensive candidate screening.

\textbf{Fast loop: generation and screening.} Designer and critic agents iteratively propose and refine code-construction programs. Executable tools check algebraic validity and resource constraints, extract inexpensive structural features, and return violations for repair. A lightweight learned screening model uses these features and the specified evaluation settings to predict circuit-level performance and uncertainty. A budget-aware allocator selects a subset of valid candidates for the slow loop, balancing predicted quality with exploration rather than relying solely on fixed code-level scores.

\textbf{Slow loop: evaluation and feedback.} Selected codes are compiled into syndrome-extraction circuits under the target hardware constraints, then evaluated through noisy sampling and decoding to estimate logical error rates (LERs) and their statistical uncertainty. The results support \textbf{two feedback paths}: structured records of constructions, implementation costs, and performance estimates guide the agents' next proposals; the same observations update the screening model to improve subsequent candidate ranking. Algebraic checks remain independent of learned predictions, and final candidate quality is assessed through circuit-level evaluation, not screening scores. By improving both \emph{what to generate} and \emph{what to evaluate}, AgentQEC aims to reduce end-to-end discovery cost at a target QEC quality, accounting for inference, tool execution, and model-update overhead.

\section*{Agentic System Efficiency and QEC Quality}
Following cost-aware agent evaluation~\cite{agentsmatter,costpass}, we adapt \textbf{cost-of-pass}: total LLM expenditure across all trials (including failures) divided by successful trials. Success requires a code meeting preset circuit-level LER and resource targets. Within each code family, we report \textbf{tokens per success, dollar cost per success, time to target, and success rate at fixed budgets}. Tokens cover all agent calls and retries, counting reported reasoning tokens once; dollar costs use model-specific prices. Tool CPU/GPU-hours and screening-update overhead are measured separately. Common hardware, noise, decoder, and validation protocols support comparisons at matched QEC quality and matched budgets.
